Zona de peligro

Borra todas las sesiones de captura, dispositivos, protocolos, flujos y hallazgos de vulnerabilidades -- para arrancar una captura completamente en blanco. Los usuarios no se ven afectados. Esta acción no se puede deshacer.

Envía tráfico a la red para identificar equipos que la captura pasiva todavía no vio -- a diferencia de Captura, esto no es pasivo. Elegí el sensor y la interfaz sobre la que transmitir antes de escanear.

PROFINET DCP

Manda un broadcast "Identify All" (el mismo mecanismo de Siemens PRONETA y TIA Portal "accessible devices") y escucha las respuestas -- encuentra equipos PROFINET aunque todavía no tengan IP configurada.

Nmap

Escaneo liviano: puertos comunes (~100), detección de servicio/versión rápida y sistema operativo -- sin scripts NSE ni escaneo agresivo, útil para análisis de vulnerabilidades.
